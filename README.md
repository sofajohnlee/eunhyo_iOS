# eunhyo_iOS

SwiftUI native iOS port of `sofajohnlee/eunhyo2`.

## Implemented

- Main navigation and elementary / middle / high school menus
- Korean study basics
- English study and speech
- Math arithmetic practice, scoring and progress persistence
- Hanja study and speech
- History and learning utilities
- Settings and local learning-state storage
- AI learning chat baseline
- Alphabet tracing
- English word practice
- Korean spelling practice
- Korean idiom practice
- GCD / LCM calculator
- Length and mass conversion
- Typing practice
- Maze practice
- Board-game score tracker

## Android parity work remaining

The Android source also includes richer AIML assets and chat behavior, phonics coloring, English sentence import, PDF library, drawing practice, geometry canvas, Golden Bell quiz, graph tools, Hanja radicals, Korean book/editor, songs/media, country study, education links, legacy gallery/slideshow, study mail, sports, magic, personality quiz, math state/progress detail screens and data transfer.

These modules will be ported incrementally to native SwiftUI equivalents.

## Run

Open `eunhyo_iOS.xcodeproj` in Xcode 16 or newer, select a signing team, choose an iPhone/iPad simulator or device, and Run.
